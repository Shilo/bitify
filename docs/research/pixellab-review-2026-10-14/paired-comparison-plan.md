# Paired palette service comparison plan

Date: October 14, 2026. Follow-up baseline `5124e77`.

The purpose is to challenge Colorfetti directly against the same-input service results, distinguish real advantages from different contracts, and select improvements that preserve a local sprite recoloring workflow. Passing independent correctness tests does not establish comparative output quality.

## Responsibilities and checkpoints

- Kernel researcher: exact-source/target replay of archived service reductions, a bounded set of new paired sprite reductions, numerical and visual comparisons, reproducible evidence and explicit confounds.
- Feature reviewer: current public website/REST/MCP palette surface matrix, directly exercised workbench operations where possible, actionable product gaps, and independent challenge of paired methodology and conclusions.
- Integration owner: clarify dither strength and pattern sizes without changing the conversion kernel; retain defaults, ownership and mobile usability.
- Root: browser and USB Android validation, direct visual comparison, evidence reconciliation, final priorities and frequent local commits. Do not push.

## Comparison rules

Use identical decoded sources and targets for fixed-palette comparisons. Compare equal requested budgets for automatic reduction using Colorfetti's actual current Auto-plus-cap pipeline, and identify direct-generation differences. Record dither strengths as distinct controls; matching labels or numeric ratios do not establish equivalent behavior. Check visible RGB membership, dimensions, exact target-member preservation, alpha, counts, unchanged-coordinate temporal stability and encoded output. Separate point distortion from spatial average error and subjective sprite readability. Include original sprites, gradients, rare accents, transparency and animations; synthetic evidence cannot establish universal artistic superiority.

Prefer already retained service outputs before spending. Up to twelve additional reducer requests are planned only for missing paired cases; each currently reports0.1 subscription generations. Track actual reported use, and do not equate subscription units with dollars. Free documented workbench calls can clarify palette extraction, ramps and snapping. No service-specific implementation details or reference files enter the four neutral research spikes.

## Completion criteria

Retain a browsable side-by-side gallery and machine-readable paired results; give concrete wins, losses, ties and unknowns. Every recommended feature must state the user benefit and acceptance criterion. Independent review must challenge cherry-picked metrics and contract differences. Verify the UI on desktop,320px width and the physical USB Android device if connected, including conditional visibility, range commits and preview/export consistency. Commit each reviewable milestone without including credentials or temporary browser profiles.
